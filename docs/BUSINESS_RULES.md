## Консервативные рабочие интерпретации

Это реализационные ограничения, а не дополнительные геологические решения.

- Самостоятельная граница — начало отдельного исходного блока `Верх:`/`Низ:`
  с содержанием или `число м —` с известным начальным литотипом/переслаиванием/
  корой выветривания. Последующие обычные блоки продолжают текущую часть.
  Необходимы минимум две доказанные границы и отсутствие преамбулы.
  Неясный числовой префикс, ссылка а.в.о., относительная отметка либо
  частично распознанная структура отменяют split: всё описание остаётся в W,
  `split_ambiguous / REVIEW_REQUIRED`. Упоминание второй породы/линзы само по
  себе не является границей. Абсолютные глубины из мощностей не вычисляются.
- `CorePart` имеет неизменяемые parent/source refs, порядковый индекс, исходные
  блоки/raw, W и полуоткрытый диапазон в полном нормализованном тексте родителя.
  Между частями допустим только исходный разделитель абзацев. Проверяются
  восстановление полного родителя, порядок блоков и числовые токены.
- Полный дубль требует совпадения интервала, J/K, безопасно нормализованного
  текста, всех метрик и контекста левой ячейки, кроме отдельного номера керна.
  Нормализация сравнения меняет только пробелы. Разные примечания, проценты,
  интервалы, отрицания или породы препятствуют удалению. Это строже минимального
  совпадения интервала/метрик. Каждое решение хранит оба ID/SourceRef,
  сравниваемые поля и влияние на суммы. Исходная запись остаётся в модели,
  Реестре, Источниках и приватном batch JSON.
- В итогах J/K родитель учитывается единожды после доказанной дедупликации.
  Если J нулевого интервала не объявлена, она остаётся пустой. Длина интервала
  показана отдельным показателем `sampling_interval_span_not_J`; её нельзя
  выдавать за объявленную проходку. Итог J в этом случае неполный.
- Разные допустимые источники K не выбираются молча: конфликт блокирует
  публикацию. `в коробках 0` допустимо как свидетельство нуля только для пустого
  интервала. Противоречие положительного и нулевого выноса блокируется.
  J≤0 и отрицательный K блокируются. Нет данных — нет фиктивных значений.
- Итог «поднято керна» может отражать коробки или иной охват. Разница с новой
  суммой K — диагностический review с источниками и оговоркой сопоставимости,
  а не основание исправить отдельные записи. Явный линейный итог имеет
  самостоятельный provenance. Неизвестный охват сверяет специалист.
- U использует ограниченный открыто перечисленный словарь. Несколько пород
  в первой фразе без явного переслаивания дают пустую U. Неясное целое описание
  после отказа split также не получает предполагаемую доминирующую породу.
  V сохраняет буквальные предложения/клаузы только с явными признаками нефти/
  углеводородов. Отрицание в той же клаузе исключает положительную метку.
  Отсылки, цвет, УРД, углистость и сульфиды не повышают степень насыщения.
- Исходный регистр/суффикс идентификатора Word не меняется. D по прежнему
  получает `metadata.well`; X получает тот же документальный идентификатор.
  Операторский/справочный номер не угадывается из шаблона или имени файла.
- Нормализация W не расширена до автоматической склейки слов: сомнительный
  дефис/перенос сохраняется. Допуск убрать технический перенос не обязывает
  удалять его. Raw всегда сохраняется отдельно.

## Учёт пакета и пригодность контроля

Каждый верхнеуровневый кандидат DOC/DOCX, без учёта регистра расширения,
попадает в census. Office `~$` и symlink имеют явный `skipped` с причиной.
Точка/кириллица в имени не исключает документ. Рекурсии нет; XLSX и каталоги
результатов не входят. Коллизии basename блокируют оба документа с кодом;
существующий результат даёт `skipped: target_exists`. Перезаписи нет без флага.

Общая сумма `converted_pass + converted_review + unsupported + error +
skipped_with_reason = discovered`; `queued` исключает только discovery skips.
CLI/GUI используют общий сервис, получают поимённые исходы, точные счётчики
и уникальный приватный batch JSON, включающий census и полную модель.

Контроль содержит русский статус, PENDING приёмку, легенду, отдельные проблемы,
понятные ID/интервалы, прямую/обратную навигацию. Реестр отделяет родителей,
части, исходный % Word, исключённые дубли и итоги; Источники сохраняют блоки.
Ожидаемые однотипные предупреждения сгруппированы; критические не скрыты.
Нулевой выход имеет голубую строку без геологического слоя/W.

## Нерешённые случаи

Неизвестные грамматики, содержательные textboxes и недоказанная полнота дают
UNSUPPORTED; неизвестные критические issues по прежнему fail closed.
Распознавание геологических границ по смыслу и нормализация номера скважины
не согласованы. Человек подтверждает спорные границы/геологию и визуальную
читаемость Excel отдельно. Программа не исправляет исходные Word.
