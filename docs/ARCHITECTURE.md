# Архитектура

`word` → `ImportedDocument` → чистый `parser` → `validation` → `excel.writer`.
GUI worker и CLI вызывают один `service.convert_batch`. Сетевых операций в
этом пути нет; получение зависимостей/исходников выполняется только сборкой.

Raw text и `TextBlock.raw` отделены от `text`. Блок содержит имя файла, порядок
и XML-путь/диапазон CP. NFC, неразрывный и повторный горизонтальный пробел
нормализуются; числа, дефисы, тире и параграфы сохраняются. W соединяет блоки
переводом строки. DOCX обходится в XML-порядке. MS-DOC читает главную story
через FIB/CLX/PlcPcd, без эвристического сканирования бинарных байтов.

Якоря начала блока: `Долбление N`, `Слой N`, `Пласт ...`, `Доюрский комплекс`,
`Всего`, подписи. Интервалы извлекаются только из заголовка слоя/сведений
долбления. Два интервала означают бурение/ГИС; один считается общим только при
явном «по бурению и каротажу». Сведения долбления объединяются до первого слоя.
Относительные интервалы внутри описания не становятся абсолютными глубинами.
После «Всего» текст исключается до нового долбления. Метаданные — только шапка;
месторождение требует `Месторождение:`. Другие формулировки оставляют поле пустым.

U ограничено однозначным начальным названием породы, V сохраняет буквальные
предложения, включая отрицания. Смешанные литологии оставляют U пустым.
Автоматической дегифенации/додумывания текста нет. Стратиграфия следует явному
предшествующему заголовку, включая переход через долбление, без проверки пересечения.

Критические: повреждение структуры, обратные интервалы, дубликаты, перекрытия.
Пропуски номеров, неизвестные поля, расхождения мощности — предупреждения.
Допуск 0,01 м не изменяет значений. Неполный вынос допустим.

Шаблон проверяется по каждому заголовку, формулы используют найденные столбцы.
Тексты — тип `s`, без гиперссылок; формулы только L/M. Временный файл создаётся
в целевом каталоге, проверяется ZIP CRC. При явной замене — `os.replace`;
без замены — Windows `os.rename`, POSIX `os.link` с запретом коллизии. Это
намеренное отличие от безусловного replace, допускающего конкурентную перезапись.
Файловая система без hardlink на POSIX даёт безопасный отказ.

Размеры, число блоков и позиции ограничены. Шифрование/неподдерживаемые
конструкции отклоняются, VBA/поля/вложения не исполняются. Это текстовый reader,
не полный движок Word: скрытые стили и визуальная раскладка не интерпретируются.
Полнота основного текста и его геологическая трактовка проверяются отдельно.
