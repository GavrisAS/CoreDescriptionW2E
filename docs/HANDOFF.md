# Передача для аудита

Реализованы отдельные импортеры DOC/DOCX, типизированная модель, парсер,
валидатор, Excel writer, общий batch-сервис, CLI и Qt GUI с worker thread.
Связи — ARCHITECTURE.md; схема — writer.HEADERS и README.

Локальный Linux Python 3.14: uv sync --locked, Ruff, ty и 40 pytest проходят.
Пользовательский образец проверен только локально, W сверён с источником и
независимым импортом. Входы, книга и сводка не входят в Git. Количества и
интервалы — только в приватном data/output/validation-summary.json.

Неоднозначности: нераспознанная метка проходки, отсутствие конечной отметки
одного описания, сложные литологии, неизвестные метаданные, несовпадение номера
в примере шаблона. Значения не исправлялись и не брались из примерных строк.

Windows workflow и лицензирование реализованы; фактический статус GitHub и
frozen acceptance будет добавлен после публикации исходников. Пока общий
статус PARTIAL. Визуальная приёмка в Microsoft Excel не проводилась.
DOC поддерживает основной текст Word 97–2003, не полный движок отображения.

Воспроизведение: TESTING.md и RELEASE.md. Приватные документы, пути и отчёты
не загружать в issues, artifacts или логи CI.
